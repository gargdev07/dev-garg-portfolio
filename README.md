# Dev Garg — Personal Portfolio

A lightweight, responsive personal portfolio for **Dev Garg**, featuring an interactive dessert solar system navigation, dynamic starfield canvas, projects, skills, and contact links.

Live Site: [https://gargdev07.github.io/dev-garg-portfolio/](https://gargdev07.github.io/dev-garg-portfolio/)

## Features

- **Dessert Solar System Navigation**: Orbiting dessert planets (🍩 Donut, 🍪 Cookie, 🍦 Ice Cream, 🍰 Cake) that rotate and smoothly fly to sections on click.
- **Interactive Twinkling Starfield**: Canvas-based stars that drift with pointer movement and adapt to screen resizing.
- **Projects**: Highlights PropAnalytics, Apple (AAPL) time-series forecasting, and interactive data science showcases.
- **Weight on Other Worlds Calculator**: Live calculation of your weight across the solar system based on planetary gravity ratios.
- **Contact**: Quick mailto, one-click email copy to clipboard, and direct webmail compose option.

## Tech Stack

- **HTML5** & **Vanilla CSS** (No heavy frameworks or build steps required)
- **Vanilla JavaScript** (ES6+)
- **Google Fonts**: Fredoka & Newsreader

## Local Preview

Open `index.html` directly in any web browser, or run a local server:

```sh
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Deployment

Hosted on **GitHub Pages** directly from the `main` branch.
